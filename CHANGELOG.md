## [Unreleased]

### Added

- OpenAI-compatible `/v1/chat/completions` proxy endpoint with streaming support.
- Anthropic provider backend with streaming response forwarding.
- `RequireAuth` extractor for API key validation on protected routes.
- SurrealDB backend crate (`valymux-surrealdb`) with AES-GCM encryption and
  PBKDF2 key derivation for stored provider secrets.
- Telemetry crate (`telemetry`) with structured logging in JSON, pretty, and
  compact formats via `tracing-subscriber`.
- Core error crate (`valymux-core`) with `AppError` and Axum `IntoResponse`
  integration.
- `AppConfig` loaded from environment variables via `envy`.
- Graceful shutdown on `SIGINT` and `SIGTERM`.
- `HttpClient` trait for abstracting the outbound HTTP client.
- Virtual API key generation and validation.
- Prometheus-compatible metrics: `latency_p95`, `errors_total` (via
  `tower-http` trace layer).
- Workspace-level dependency management with `resolver = "3"` (Rust 2024
  edition).

### Changed

- Project renamed from ValyGate to ValyMux.
- Migrated SurrealDB client to `surrealdb-types` 3.x API.
